HTML, CSS, JS, Tailwind?

Hypertext Markup Language

HTML, singkatan dari HyperText Markup Language, adalah bahasa standar yang digunakan untuk membuat struktur dasar dan konten halaman web. Fungsinya adalah untuk memberi tahu peramban (browser) cara menampilkan teks, gambar, tautan, dan elemen lainnya di sebuah halaman web, seperti kerangka dasar sebuah rumah yang menentukan tata letak. HTML menjadi fondasi untuk hampir semua situs web.

Cascading Style Sheet

CSS, singkatan dari Cascading Style Sheets, adalah bahasa yang digunakan untuk mendeskripsikan tampilan dan format dokumen yang ditulis dalam bahasa markup seperti HTML atau XML. CSS berfungsi untuk memisahkan konten dari tampilan visualnya, memungkinkan pengembang untuk mengatur elemen seperti tata letak, warna, font, dan jarak antar elemen pada halaman web.

Javascript

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web interaktif dan dinamis, bekerja bersama HTML (struktur) dan CSS (tampilan). Ini memungkinkan pengembang untuk menambahkan fitur seperti animasi, pembaruan konten, dan fungsi interaktif lainnya ke situs web. JavaScript digunakan secara luas dan menjadi bagian penting dari pengembangan web modern, bahkan dapat digunakan untuk pengembangan sisi server dan Internet of Things (IoT).

Tailwind

Tailwind adalah framework CSS utility-first untuk membangun antarmuka pengguna (UI) dengan cepat. Tidak seperti framework lain yang menyediakan komponen siap pakai (seperti Bootstrap), Tailwind memberikan banyak kelas utilitas kecil yang bisa digabungkan langsung di HTML untuk menyesuaikan tampilan secara kustom.

Tutorial Make A Simple Website

1.

Tentukan Tujuan Website

Sebelum Membuat Website, kita harus tau dulu tujuan kita untuk membuat website tersebut, apakah website itu untuk profil pribadi(portofolio), untuk bisnis atau toko online, atau hanya untuk belajar web. Tujuan ini penting supaya kamu tahu struktur dan konten yang akan dibuat

2

Pilih Editor Kode HTML

Editor kode adalah software yang digunakan untuk menulis coding website. Meskipun bisa menggunakan editor teks default seperti Notepad untuk membuat halaman HTML, aplikasi tersebut tidak memiliki fitur penting untuk menyederhanakan proses development

3

Rencanakan Tata Letak Website

Selanjutnya, Anda perlu membuat rencana tata letak (layout) yang matang dalam cara membuat website dengan HTML dan CSS. Sebab, hal ini akan memungkinkan Anda memvisualkan tampilan website dengan lebih baik.

4

Mulai Tulis Kode HTML

Setelah rencana layout dan tool siap, Anda bisa mulai menulis kode untuk memulai cara membuat website dengan HTML. Langkah-langkahnya mungkin bervariasi tergantung pada editor kode yang Anda gunakan, tapi proses dasarnya tetap sama.

5

Buat Element Tata Letak

Tambahkan kode HTML ke dalam file index.html untuk membuat elemen-elemen dari rencana layout Anda. Tergantung pada desain website Anda, mungkin akan diperlukan beberapa elemen semantik HTML yang berbeda.

6

Tambahkan Konten HTML

Apabila layout sudah siap, mulailah mengisinya dengan konten website, seperti teks, gambar, link, atau video. Kalau konten Anda belum siap, gunakan sampel konten apa pun sebagai placeholder, kemudian Anda bisa menggantinya nanti.

7

Sertakan CSS Tata Letak

Untuk membuat layout website dua kolom, kami akan menggunakan properti flex. Properti ini berfungsi untuk mengatur elemen HTML menggunakan tempat penampung yang fleksibel sehingga bisa menyesuaikan ukuran layar pengguna.

8

Sesuaikan Tampilan Website HTML

Selain mengubah tata letak, gunakan CSS untuk menyesuaikan aspek visual lain website Anda. Misalnya, Anda bisa mengganti jenis font dan gambar latar belakang website.
